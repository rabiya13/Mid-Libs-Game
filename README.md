# Mid-Libs-Game
Mad Libs is a fun and interactive word game where players create a humorous story by filling in blanks with various types of words — such as nouns, verbs, adjectives, and adverbs — without knowing the context of the story.This Python implementation of Mad Libs is a simple console-based game that prompts the user for different parts of speech. 

# Features – Mad Libs Game
 Interactive console-based word game

Surprises users with a hidden story structure

Accepts inputs for nouns, verbs, adjectives, etc.

Option to replay the game after each round

Simple input validation for blank entries

 Beginner-friendly Python code (great for learning)
